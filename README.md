# アルル制作所｜完成見学会マーケティングSkill

工務店・住宅会社向けの、完成見学会販促物制作Skill集です。

住宅写真から、完成見学会のタイトル・キャッチコピー候補を作り、番号選択でInstagram画像、LINE画像、A4縦横チラシ、告知文、予約案内、来場前後のフォローなどへ展開します。

## インストール

Windows PowerShellで次を実行してください。

```powershell
irm https://raw.githubusercontent.com/aruru737/aruru-openhouse-skill/main/install.ps1 | iex
```

インストール後にCodexを再起動し、住宅写真を添付して、

```text
完成見学会の資料を作って
```

と入力してください。

## 収録Skill

19個の完成見学会関連Skillを収録しています。

## 注意事項

住宅写真から確認できない性能・仕様・住所・開催日時などを自動で創作しない方針で設計しています。
