# アルル制作所｜完成見学会マーケティングSkill v2.0.0

工務店・住宅会社向けの、完成見学会販促物制作Skill集です。

住宅写真をもとに、ネーミング、SNS画像、LINE画像、チラシ、投稿文、Web告知、予約案内、来場前後フォローまでを番号選択で作成します。

## v2.0.0 の主な改善

- タイトル・キャッチコピー・説明を必ず表形式で表示
- 0番を「開催場所・日程・詳細を入力・更新する」に固定
- 1〜8番をセット制作に統一
- 101〜114番を個別制作に統一
- 199番を終了に固定
- Instagram / LINE画像の文字をスマホで読める大きさに改善
- 画像系の完成結果は各媒体1枚だけ表示
- A4縦横チラシのレイアウト、文字階層、情報密度、写真配置を強化
- 余計な作業宣言や内部処理説明を出さず、生成結果のみ表示
- セット制作では途中で何度も番号入力を求めない

## インストール

Windows PowerShellで次を実行してください。

```powershell
irm https://raw.githubusercontent.com/aruru737/aruru-openhouse-skill/main/install.ps1 | iex
```

インストール後にCodexを再起動し、住宅写真を添付して、

```text
完成見学会の資料を作って
```

と入力してください。

## メニュー構造

- 0：開催情報入力・更新
- 1〜8：まとめて制作するセット
- 101〜114：個別制作
- 199：終了
