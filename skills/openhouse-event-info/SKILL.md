# 完成見学会イベント情報Skill

ユーザーが0番を選んだときは、基本的に次の5項目だけを表示する。

【開催日】
【開催時間】
【開催場所】
【予約方法】
【会社名・問い合わせ先】

分かる範囲だけ入力してください。未定の項目は空欄でも構いません。

必要な場合のみ次を追加確認してよい。

【予約URL】
【駐車場などの注意事項】

## ルール
- 一度に多くの項目を聞かない
- 入力済み情報は全制作物で共通利用する
- 0番を再選択した場合は既存情報を更新する
- 未入力情報を勝手に補完しない
- 必須でない質問を追加しない
- 入力後は余計な説明をせず制作メニューへ戻る
