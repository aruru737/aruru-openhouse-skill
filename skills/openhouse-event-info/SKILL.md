# 完成見学会イベント情報Skill

## 保持項目

- 開催日
- 開催時間
- 会場名またはエリア
- 住所
- 完全予約制か
- 予約方法
- 予約URL
- QRコード画像
- 電話番号
- 会社名
- ロゴ
- 問い合わせ先
- 駐車場等の注意事項

## 方針

画像レイアウトだけ先に作れる場合は、情報不足を理由に制作を止めない。
未入力項目は架空の値で埋めない。

未入力欄は、
「開催日時」「会場」「ご予約はこちら」などの見出しと
後から差し替えやすい余白・プレースホルダーとして確保してよい。

最終版として確定情報が必須な場合のみ、一度にまとめて必要項目を尋ねる。
