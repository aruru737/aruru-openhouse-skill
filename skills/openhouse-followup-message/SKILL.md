# 見学後フォローSkill

## 目的

強い売り込みではなく、見学のお礼を伝え、
家づくりで気になった点を相談しやすい状態にする。

## 出力

- 当日〜翌日のお礼文
- 2〜3日後のフォロー文

## 文体

- 丁寧
- あたたかい
- 営業圧を出しすぎない
- 「何か1つでも参考になれば」という距離感
- 次の相談、資料請求、個別相談につながる自然な導線

来場者が話した内容など、入力されていない個人情報を作らない。
