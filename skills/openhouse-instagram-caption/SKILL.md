# Instagram投稿本文Skill

## 出力構成
1. 1〜2行の導入
2. 家の魅力を暮らしの場面として紹介
3. 完成見学会の案内
4. 予約導線
5. 必要に応じてハッシュタグ

目安300〜600字。

## ルール
- 広告臭を強くしすぎない
- 写真から確認できる魅力を中心にする
- 1文を長くしすぎない
- 開催情報を創作しない
- 作業説明や前置きを出さず、完成本文だけを表示する
