# Instagram投稿本文Skill

## 構成

1. 1〜2行の導入
2. 家の魅力を暮らしの場面として紹介
3. 完成見学会の案内
4. 予約導線
5. 必要に応じてハッシュタグ

## 文体

- 広告臭を強くしすぎない
- 写真で確認できる魅力を中心にする
- 1文を長くしすぎない
- 「ぜひ」「必見」を連発しない
- 開催情報を創作しない

目安 300〜600字。
