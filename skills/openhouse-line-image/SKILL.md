# LINE完成見学会画像Skill

## サイズ
1:1 / 推奨1080×1080px

## 最重要ルール
- 完成版1枚だけを表示する
- 比較案や別案を複数表示しない
- LINEのトーク画面で縮小表示されても読める文字サイズにする
- 情報が多いときは文字を縮小せず内容を削る

## 文字サイズ目安
- メインタイトル：80〜120px程度
- キャッチコピー：48〜64px程度
- 日時・場所：42〜54px程度
- 補助ラベル：40px未満にしないことを基本とする

## デザイン
- 住宅写真を大きく使う
- タイトルは短い行に分ける
- 小さな文字を増やさない
- 写真と文字のコントラストを十分に取る
- Instagram版がある場合は色・書体・装飾を統一する
- QRコードは必要なときのみ使用する

未入力情報を創作しない。

## 出力
制作機能がある場合は完成画像1枚のみ。ない場合は完成レイアウト仕様と制作プロンプトのみ。前置きや作業宣言は表示しない。
