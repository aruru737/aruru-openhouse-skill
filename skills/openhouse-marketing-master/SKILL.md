# 完成見学会マーケティング完全統合Skill

## 最優先ルール
- ユーザーには生成結果だけを表示する。
- 内部思考、分析過程、作業宣言、処理方針は表示しない。
- 「これから作ります」「各Skillを使って整理します」等の前置きを出さない。
- 必要な確認がある場合だけ、必要最小限の質問をする。
- 写真から分からない情報を創作しない。
- 住宅の形、窓、外壁、屋根、庭などを別物に改変しない。
- 画像系制作物は媒体ごとに完成版1枚だけを表示する。
- 同一案件ではタイトル、キャッチコピー、説明、配色、書体方向を共通利用する。
- 0は開催情報入力、1〜8はセット制作、101〜114は個別制作、199は終了に固定する。

## 起動
住宅写真とともに「完成見学会の資料を作って」「この家の完成見学会資料を作成して」「見学会用の販促物を作って」等の依頼で起動する。
写真は1枚でも開始可。推奨3〜10枚。

# STEP 1 写真確認
内部で次を確認し、結果は表示しない。
- 建物全体が分かる外観
- 光、抜け、広がりが分かるLDK
- 庭や中庭とのつながり
- 吹き抜け、窓、造作など特徴的な箇所
- 明るさ、ピント、水平、見栄え
- 同じ構図の重複を避ける

媒体別選定：
- Instagram 4:5：縦トリミングしても主役が残る写真
- LINE 1:1：中央に強い被写体がある写真
- A4縦：主役1枚＋補助2〜4枚
- A4横：横方向の広がりがある外観・LDK
- ストーリーズ：縦長で重要部分が中央に残る写真

# STEP 2 ネーミング
10案を作る。

タイトル：
- 10文字以上
- 目安10〜25文字
- 30文字以内推奨
- 10案の方向性を似せすぎない

キャッチコピー：
- 15〜35文字程度
- 設備説明ではなく暮らしの情景が浮かぶ文章

説明：
- 各案約150字
- 暮らしのワンシーン
- 写真から確実に読み取れる特徴
- そこで生まれる時間や感覚

写真だけでは分からない高気密、高断熱、耐震等級、断熱等級、ZEH、長期優良住宅、省エネ性能、床暖房、家事動線や収納力の断定、家族構成、住人の職業や年齢を創作しない。

# セット実行
- セットを選んだら含まれる制作物を連続して作成する。
- セット内で毎回番号入力を求めない。
- 不足情報が制作を妨げる場合だけ、一度にまとめて最小限確認する。
- 画像系は各媒体1枚だけを最終結果として表示する。
- 同一セット内ではデザイン世界観を統一する。
- セット完了後に制作メニューへ戻る。

# 101 Instagram投稿本文
300〜600字。導入→暮らしの場面→見学会案内→予約導線→必要に応じハッシュタグ。
広告臭を強くしすぎず、写真から確認できる魅力を中心にし、完成本文だけを表示する。

# 102 LINE配信メッセージ
150〜300字。完成見学会開催のお知らせ→タイトル→住宅の魅力2〜4行→日時・場所→予約方法→CTA。
完成メッセージだけを表示する。

# 103 Web・ホームページ告知文
ページタイトル、リード文、300〜700字本文、開催概要、予約導線。
写真から確認できる魅力と暮らしの情景を中心にし、未入力情報は創作しない。

# 104 Instagram投稿用画像
4:5 / 推奨1080×1350px。
完成版1枚だけ。スマホ可読性最優先。
目安：タイトル80〜120px、キャッチ48〜64px、開催情報40〜52px。
文字が多い場合は縮小せず内容を削る。
住宅写真を主役にし、タイトルを最も大きく、コントラストを確保し、余白は取るがスカスカにしない。
住宅そのものは改変しない。

# 105 LINE配信用画像
1:1 / 推奨1080×1080px。
完成版1枚だけ。LINEのトーク画面で縮小表示されても読める大きさ。
目安：タイトル80〜120px、キャッチ48〜64px、日時・場所42〜54px。
小さな文字を増やさず、Instagram版と世界観を統一する。

# 106 Instagramストーリーズ画像
9:16 / 推奨1080×1920px。
完成版1枚のみ。住宅写真を大きく使い、上下UI領域を避け、タイトル・キャッチ・開催情報をスマホで読める大きさにする。

# 107 Instagramリール構成
15〜30秒。
0〜3秒：外観または特徴的な一枚＋強いタイトル
3〜8秒：室内へ入る流れ
8〜15秒：窓、庭、吹き抜け等の見どころ
15〜22秒：暮らしを想像させるカット
22〜30秒：完成見学会情報・予約導線

出力：
| 秒数 | 使用写真・カット | 画面テキスト | 動き | ナレーション・字幕 |
|---|---|---|---|---|

ズームだけに頼らず、文字は1〜2秒で読める短さにする。

# 108 Googleビジネスプロフィール告知文
投稿タイトル、150〜300字本文、短いCTA。
地域の人が流し読みして内容を把握できるようにし、未入力情報は創作しない。

# 109 A4縦チラシ
A4縦 210×297mm。
完成版1枚のみ。小さすぎる文字禁止。余白を取りすぎず、写真、タイトル、開催情報、予約導線の視線順を明確にする。
上部：ラベル＋大きなタイトル＋キャッチ＋主役写真
中部：補助写真2〜4枚＋見どころ
下部：開催日・時間・会場・予約方法・QR・会社名
文字目安：タイトル28〜44pt、キャッチ18〜26pt、見出し16〜22pt、開催情報14〜20pt、本文11〜14pt。
大きな空白を残さず、写真・見どころカード・開催情報ブロックで密度を整える。
写真から1〜2色を拾いアクセントにし、カード・帯・罫線・写真の大小でリズムを作る。

# 110 A4横チラシ
A4横 297×210mm。
完成版1枚のみ。小さすぎる文字禁止。横長ならではの写真の広がりを使う。
A：左60〜65％主役写真＋右35〜40％情報
B：上60％大型写真＋下40％情報
C：全面写真＋可読性の高い情報カード
文字目安：タイトル28〜42pt、キャッチ18〜24pt、見出し15〜20pt、開催情報14〜19pt、本文11〜14pt。
片側だけ空きすぎないよう、補助写真・見どころ・開催情報を再配置する。

# 111 A3完成見学会ポスター
A3縦を基本。完成版1枚のみ。
住宅写真→タイトル→キャッチ→開催日時・会場→予約導線の順に優先する。
離れて見てもタイトルが読める大きさにし、本文を詰め込みすぎない。

# 112 来場予約フォーム・予約案内文
予約ページ見出し、予約前案内、推奨入力項目、予約完了メッセージ、必要に応じ変更・キャンセル案内。
推奨入力：氏名、メール、電話、希望日時、来場人数、任意質問。
不要な個人情報を過剰に求めない。

# 113 来場前リマインドメッセージ
前日用・当日用を作る。
予約のお礼、日時、会場、必要なら駐車場・受付、変更・キャンセル連絡、来場を待っている旨を含める。
完成文だけ表示する。

# 114 見学後のお礼・フォローメッセージ
当日〜翌日用、2〜3日後用を作る。
丁寧であたたかく、営業圧を出しすぎず、自然な相談導線を作る。
完成文だけ表示する。

# 最終チェック
表示前に内部で確認する。チェック過程は表示しない。
- タイトル、キャッチコピーが選択内容と一致
- 誤字脱字なし
- 他案件の情報が混ざっていない
- 架空の日付・住所・性能・電話番号を作っていない
- 住宅写真を改変していない
- SNS画像の文字がスマホで読める
- 画像は媒体ごとに完成版1枚
- チラシの本文は11pt未満相当になっていないことを基本とする
- チラシの余白が空きすぎていない
- 開催情報が1か所に整理されている

# 終了
199が選ばれたら簡潔に終了する。長いまとめや追加営業を表示しない。
