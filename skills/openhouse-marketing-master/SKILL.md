# 完成見学会マーケティング

## 共通ルール

- 写真とユーザーが渡した情報にない事実を作らない。日付、住所、性能、価格、予約URLなどは未確認のまま補わない。
- 写真で確認できる事実と、未来の住まい手が想像できる暮らしの情景を分けて扱う。施主の実話や住宅性能として断定しない。
- 住宅の形状、窓、外壁、屋根、庭、素材感を別物に変更しない。
- 日本語の主書体は上品な明朝体を基本とし、アイボリー・チャコール・ブロンズを基調にする。
- 文字の縦横比を変えない。収まらない場合は、改行、文字サイズ、字間、行間、文章量、テキスト領域の順に調整する。
- 内部の分析過程、参照手順、進捗はユーザーへ表示せず、完成物と必要なリンクを中心に返す。

## セット6が選ばれたとき

1. 入力写真と確認済み情報を整理し、主役写真・補助写真・使用可否を決める。
2. 次のLP仕様を必ず読む: [references/channels/lp.md](references/channels/lp.md)
3. `index.html` と `assets/` を含む静的レスポンシブLPを制作する。外部依存は最小限にする。
4. デスクトップ（目安1440px）とスマートフォン（目安375px）で、文字切れ、横スクロール、画像の崩れ、予約導線、最終セクションを目視確認する。
5. `index.html` と必要素材だけをZIPへ収録する。個別のHTML・画像ファイルはダウンロードリンクとして並べず、ZIPリンクを一つ表示する。
6. 完成LPの代表プレビューをチャット内へ画像表示し、HTMLソース全文は求められた場合だけ掲載する。

## LPで守る内容

- ファーストビュー、暮らしの物語、見どころ、庭とのつながり、ギャラリー、申し込みステップ、開催情報・予約導線を一つの流れにする。
- h1・h2は日本語の読点「、」を使わず、意味を保った自然な改行にする。
- h1・h2が3行以上になりそうな場合は、まずフォントサイズと行間を下げて2行以内へ収める。文字を変形しない。
- 背景写真に重なる文字には、薄い黒系の枠または半透明パネルを敷き、写真の明るさに左右されず読めるようにする。
- 小さすぎる文字を残さない。ヘッダー、フッター、ラベル、キャプション、補足文、予約カードの注意書きまで、スマートフォンで読めるサイズと行間を確保する。
- 申し込みステップは3枚を基本とし、番号と中央寄せの大きなラインアイコンを置く。カード間は大きな `▶` でつなぎ、丸い枠は付けない。スマートフォンでは大きな `▼` に切り替える。
- 最終セクションの予約文、特にLINE申し込みの文字の上に写真や装飾を重ねない。

## 出力

成果物とZIPリンクを表示した後、次の2行を完全一致で表示する。

```text
▲　▲　▲　▲　▲　▲　▲
出力はここまで
```

続けて `次はどれを作りますか？` と制作メニューを表示する。すでに制作した項目は「再作成」と表記する。
