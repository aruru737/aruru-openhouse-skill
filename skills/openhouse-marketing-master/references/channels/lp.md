# 完成見学会LP仕様

セット6「ホームページ（LP）制作」で使う。写真で伝わる住宅の魅力と、見学予約までの導線を、上品で読みやすい一枚のレスポンシブページにまとめる。

## 成果物

- 静的な `index.html` と必要素材を `assets/` に整理する。
- `index.html` と素材を一括ZIPに収録し、チャットにはZIPリンクを一つ表示する。
- デスクトップとスマートフォンの代表プレビューを確認し、プレビュー画像をチャット内へ表示する。
- HTMLソース全文はユーザーが求めた場合だけ掲載する。

## 推奨ページ構成

1. ファーストビュー: 確定タイトル、キャッチコピー、主役写真、開催概要、予約CTA
2. 暮らしの物語: キッチン・ダイニング・リビング・庭のつながりと、そこで生まれる会話を描く
3. 見どころ: 写真と確認済み情報から3項目程度を、暮らしの場面とともに紹介する
4. 庭と住まいのつながり: 大きな背景写真に、黒系の半透明パネルを重ねる
5. ギャラリー: 外観・寝室・キッチンなどを住宅形状と比率を崩さず配置し、写真ごとの短い解説を付ける
6. 申し込みステップ: 3枚のカード、中央寄せの大きなラインアイコン、番号、説明文、大きな `▶` の接続矢印
7. 最終セクション: 開催情報とLINE予約カードを左右に配置する

## ビジュアル仕様

- 配色はアイボリー／ペーパー、チャコール、ブロンズを共通トークンとして使う。
- 日本語は明朝体を主役にし、見出し・本文・ラベルの階層を明確にする。
- ファーストビューのh1は写真側へ少し広げた暗い半透明パネル内に置く。h1・h2に「、」を入れない。
- 写真に重なる見出しや引用文には、薄い黒の枠または半透明パネルを敷く。濃さは文字が読みやすい最小限にする。
- h1・h2が3行以上になる場合はフォントサイズを下げ、自然な2行以内へ調整する。長体・平体・縦横変形は禁止する。
- ヘッダーのブランド名・日付・予約ボタン、フッターの会社名・開催情報、ラベル、写真キャプション、注意書きは小さくしすぎない。目安は本文16px相当以上、補助ラベル14px相当以上とし、行間を確保する。

## 申し込みステップ

- 各カードは番号 `01` `02` `03`、中央寄せの大きな線画アイコン、見出し、短い説明文で構成する。
- デスクトップではカード間の中央に大きなブロンズ色の `▶` を置く。円形の背景、円形の枠、バッジ化は行わない。矢印そのものを大きくして次の手順を示す。
- スマートフォンではカードを縦積みにし、カード下部中央に大きな `▼` を置く。最後のカードには矢印を出さない。

## 最終セクションの確定レイアウト

- 左カラムは「開催情報」ラベル、家族の暮らしを結ぶタイトル、枠付きの「完成見学会」を置く。
- 日付と時間は「完成見学会」の右側へ配置する。日付・時間の下に「開催エリア」「予約方法」の行は作らない。
- 左カラムの下に正面外観写真を大きく置き、写真キャプションを添える。
- 右カラムは枠付きの予約カードとし、「LINEより お申し込みください」、申し込み説明、`LINEで予約` の表示、会場住所は申し込み後に案内する注意書きを置く。
- 予約カードへ写真や装飾を重ねず、LINE申し込みの文字を常に読めるようにする。
- 左右の余白は内容に合わせて自然に見える高さへ調整し、片側だけが不自然に伸びる固定高さや大きな空白を避ける。
- 主催者行は追加しない。確認済みの開催エリアや予約方法を最終セクションへ再掲する必要がない場合は省略する。

## 実装・検査

- `alt` を写真の確認可能な内容に合わせる。未確認の住所、性能、価格、URLを作らない。
- 375px前後と1440px前後で、文字切れ、横スクロール、写真のトリミング、ステップ矢印、最終セクション、LINE予約文を確認する。
- ヘッダーからフッターまで小さすぎて読めない文字がないことを確認する。
- HTTP 200、画像参照、ZIP内容（`index.html` と `assets/`）を検査してから完成扱いにする。
