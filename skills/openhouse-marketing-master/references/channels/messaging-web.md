# LINE・Web・Google媒体仕様

共通して [../editorial-tone.md](../editorial-tone.md) に従う。情報を正確に伝えながら、見学する理由を「設備」ではなく「そこで過ごしたい時間」として感じられる文章にする。

確定した「物語の核」を文章の中心に置く。媒体ごとに短縮しても、家族の場面を一般的な設備紹介へ置き換えない。

## LINE

- 250〜450文字を目安にする。
- 自然な日本語で「家」と結ぶ確定タイトルに続け、最初の2〜4行で1文のキャッチコピーと約100字の基本ストーリー文を生かし、読者が自分や家族を重ねられる生活場面を一つ描く。
- 基本ストーリー文は、見える家の特徴と空間の関係を起点にし、そのつくりだから生まれる人の動き、会話、時間へつなぐ。人物の動作だけを並べた描写にはしない。
- その後に、場面を支える見どころを2〜3点だけ伝える。
- 日時、場所、予約方法、CTAは後半で見つけやすくまとめる。
- トーク画面で読みやすい改行を使う。
- 親しい案内状のように温かく、急かす表現や営業色を強くしない。

## Web

- 自然な日本語で「家」と結ぶ確定タイトル、1文のキャッチコピー、90〜120文字程度で丁寧に見学へ招く基本ストーリー文、400〜800文字の本文、開催概要、予約導線を作る。
- 本文は「暮らしの場面 → 写真・設計上の理由 → 見学で確かめてほしいこと」の順にする。
- 見どころ見出しも「大開口」「庭」だけで終わらせず、「庭まで広がる家族の休日」など生活上の価値を含める。
- 本文では約100字の基本ストーリー文を繰り返さず、その場面の前後、家族それぞれの視点、見学時に確かめられることへ広げる。
- 仕様や性能は独立した事実欄にまとめ、情緒文と混ぜて誇張しない。
- 検索用の語を不自然に繰り返さない。
- 詳細住所を非公開にする場合は理由と案内方法を書く。

## Googleビジネスプロフィール

- 250〜500文字を目安にする。
- 冒頭に確定タイトルまたはその意味を保った一文を置き、1文のキャッチコピーを続けて、イベント内容とエリアを明示する。
- 約100字の基本ストーリー文を土台に、写真で確認できる家の特徴が暮らしの物語を生む理由まで一つ示す。
- 写真で確認できる特徴を一つ、そこから想像できる暮らしのメリットを一つに絞る。
- 開催日とCTAを簡潔にまとめ、情報の探しやすさを優先する。
- 終了後は告知を残したままにしない運用を案内する。
