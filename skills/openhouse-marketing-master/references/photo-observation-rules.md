# 住宅写真の観察ルール

写真で確認できる事実と推測を分け、誤った性能・素材・暮らし方の断定を防ぐ。

| 項目 | 内容 |
|---|---|
| 写真ID | 一意の番号 |
| 写っている空間 | 外観、LDK、キッチン、玄関など |
| 観察できる事実 | 形、配置、色、見えている設備 |
| 推測になり得る内容 | 素材名、性能、使い勝手、家族像など |
| 確信度 | 高・中・低 |
| 使用可否 | 主役・補助・使用不可 |
| 暮らしの種 | この特徴を足場に描ける未来の時間、行動、感情。観察事実とは分けて記録する |
| 注意点 | 表札、顔、車両番号、住所情報など |

## そのまま表現しやすいもの

- 写真上で明確な色、形、空間のつながり
- 窓の位置、見えている収納、カウンター、吹き抜け
- 室内から見える庭や外部空間
- 写真撮影時の光の入り方。ただし「一日中明るい」と一般化しない

## 入力確認なしでは断定しないもの

- 無垢材、漆喰、天然石などの素材名
- 高気密、高断熱、耐震性、ZEH、認定、等級
- 家事動線が良い、収納が十分、掃除しやすい等の評価
- 家族構成、生活習慣、建築主の職業
- 方角、面積、寸法、住宅設備の型番

## 画像選定

- Instagram 4:5: 縦トリミングしても主役が残る写真
- LINE 1:1: 中央に強い被写体がある写真
- A4縦: 主役1枚と補助2〜3枚を確保できる構成
- A4横: 通常は選定対象にせず、ユーザーから明示的な制作依頼がある場合だけ、横方向の広がりがある外観またはLDKを選ぶ
- ストーリーズ: 上下のUI領域を避けても主役が残る縦長写真

写真を加工するときも、住宅形状や設備配置を変えない。

## 観察から暮らしの物語へ

観察した特徴ごとに、文章へ展開できる「暮らしの種」を1〜3個考える。これは施主についての事実ではなく、未来の住まい手が想像できる場面として扱う。

- 庭と大開口: 子どもが庭へ駆け出す休日、緑を眺めるひととき、内外に広がる団らん
- 窓辺と光: ゆっくり過ごす朝、読書やコーヒー、季節の移ろい
- キッチンとLDKのつながり: 料理をしながら続く会話、家族の気配
- 落ち着いた色や木目: 一日の終わりに心がほどける時間、静かな団らん

写真で見える特徴が文章の足場になっている限り、生活場面まで写真に写っている必要はない。

複数の「暮らしの種」からタイトル案を作るときは、声、行動、時間、感情の変化が最も鮮明なものを「物語の核」の候補にする。選んだ候補には、根拠となる写真IDと観察事実を対応づける。以後のSNS、Web、印刷物、予約案内、フォロー文は同じ核から展開し、媒体ごとに無関係な物語を作り直さない。
