# 完成品質の評価

各項目を0〜2点で評価する。事実性または法令・許諾が0点なら公開不可。暮らし想起、来場意欲、デザイン完成度のいずれかが0点なら書き直す。合計16点未満は修正する。

| 項目 | 0点 | 1点 | 2点 |
|---|---|---|---|
| 事実性 | 創作・未確認事項あり | 曖昧な表現あり | 確認済み事実のみ |
| 会社適合 | 未承認表現あり | 一般的で個性が弱い | 承認済みの強みとトーンに一致 |
| 来場者適合 | 対象不明 | 属性だけに対応 | 検討段階の関心に対応 |
| 暮らし想起 | 特徴の説明・仕様の羅列だけ | 抽象的な心地よさに留まる | 人、時間、行動、感情が浮かぶ |
| 来場意欲 | 見学する理由がない | 定型的な招待だけ | この家で確かめたい具体的な一点があり、丁寧に招いている |
| 写真適合 | 写真と文言が不一致 | 関係が弱い | 写真の主役と訴求が一致 |
| デザイン完成度 | 写真に文字を載せただけで簡素 | 情報は読めるが単調 | 明朝体、写真、余白、階層、配色が上品に設計されている |
| 媒体適合 | 読めない・長すぎる | 一部調整不足 | 文字量、導線、比率が適切 |
| 媒体間整合 | 基本情報が不一致 | 表記揺れあり | 全媒体で完全一致 |
| 法令・許諾 | 問題または未確認 | 人の確認が必要 | 根拠・条件・許諾を確認済み |

## 文章の目視確認

- タイトル単独で、家族の声、行動、時間、感情のいずれかが動く一場面を想像できる
- タイトルが原則18〜30文字で、暮らしの良さがすぐ伝わる自然な日本語により「家」と結ばれている
- 抽象語や無生物を不自然に動かす比喩、回りくどい言い換え、意味の広すぎる形容がない
- 沈黙、疲れ、忙しさ、孤独、不安、寂しさ、我慢など、ネガティブな状態を入口や対比に使っていない
- キャッチコピーが原則1文、35〜60文字程度で、場面と気持ちまたは暮らしの変化を一息で描いている
- 説明欄が90〜120文字程度の原則2文で、確認できる家の特徴と空間の関係、そのつくりから生まれる行動、現地で確かめる価値を因果関係で描いている
- 説明欄が、人物の動作だけを並べた場面描写にも、住宅特徴だけを並べた仕様説明にも偏っていない
- 説明欄が丁寧な「です・ます」調で、読み手が自分の暮らしを重ねながら見学したくなる具体的な招待で結ばれている
- 複数案が同じ定型の招待文で終わっていない
- 各案で最も印象的な情景が、キャッチコピーだけでなくタイトルに反映されている
- タイトルが住宅の特徴を短く要約しただけの見出しになっていない
- 冒頭に生活の一場面または感情の入口がある
- 写真の特徴が、家族の時間や生活のゆとりへ翻訳されている
- 情緒文、根拠、開催情報の役割が混ざっていない
- 「開放的」「心地よい」「上質」などの抽象語だけで終わっていない
- SNS、LINE、Web、チラシで同じ文章をそのまま使い回していない
- 全媒体が同じ「物語の核」を共有し、主役となる場面、写真上の根拠、暮らしの価値が一致している
- 長文では物語が自然に広がり、短い媒体では印象的な一節が残り、どちらも一般的な住宅説明へ後退していない
- 画像や動画で全文が収まらない場合、意味を削るのではなく複数行・複数画面・複数カットへ適切に分けている

## 画像の目視確認

- 日本語が一字一句正しい
- 日本語の主書体が明朝体を基調とし、ゴシック体だけの硬い印象になっていない
- 文字の縦横比が保たれ、長体、平体、縦長、横長の変形がない
- 住宅形状、窓、屋根、外壁、設備配置が変わっていない
- 小さい画面でもタイトル、日程、CTAが読める
- 文字が写真の重要部分を隠していない
- ロゴ、余白、配色が会社設定に合う
- 写真へ文字を置いただけの簡素な構成ではなく、視覚的な焦点と情報のまとまりが設計されている
- Instagram画像、LINE画像、A4縦チラシに同じ書体、配色、写真表現の一貫性がある
- 建築誌風の余白、アイボリー・チャコール・ブロンズの配色、タイトルを主役にした階層がセット全体で保たれている
