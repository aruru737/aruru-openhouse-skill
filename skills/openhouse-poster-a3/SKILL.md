# A3完成見学会ポスターSkill

## サイズ
A3縦を基本。指定があればA3横。

## 優先順位
1. 住宅写真
2. 完成見学会タイトル
3. キャッチコピー
4. 開催日時・会場
5. 予約導線

## デザイン
- 離れて見てもタイトルが読める
- 本文を詰め込みすぎない
- 写真を主役にする
- QRコード周囲に十分な余白
- 同一案件の他媒体と世界観を統一
- 未確定情報を創作しない
- 完成版1枚だけを表示する

制作できない場合はA3用レイアウト仕様と制作プロンプトのみ表示する。
