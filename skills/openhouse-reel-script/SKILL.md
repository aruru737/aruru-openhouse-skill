# 完成見学会リール構成Skill

スライドショーではなく、住宅の魅力を順に発見していく短いストーリーとして構成する。

## 基本構成
1. 0〜3秒：外観または特徴的な一枚＋強いタイトル
2. 3〜8秒：室内へ入る流れ
3. 8〜15秒：窓、庭、吹き抜け等の見どころ
4. 15〜22秒：暮らしを想像させるカット
5. 22〜30秒：完成見学会情報・予約導線

## 出力
- 秒数
- 使用写真またはカット
- 画面テキスト
- 動き
- ナレーションまたは字幕案
- 最後のCTA

## ルール
- ズームイン・ズームアウトだけに頼らない
- 文字は1〜2秒で読める短さ
- 住宅にない設備・性能を創作しない
- 写真素材だけの場合、実写動画があるように偽らない
