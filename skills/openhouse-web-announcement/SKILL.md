# Web・ホームページ告知文Skill

## 出力
- ページタイトル
- リード文
- 300〜700字程度の本文
- 開催概要
- 予約導線

## 方針
- 検索向けキーワードを不自然に詰め込まない
- 写真から確認できる魅力を中心にする
- 暮らしの情景を入れる
- 未入力の日時、住所、性能、仕様を創作しない
- 予約ページへ自然につなげる

必要に応じて見出し構成も付ける。
